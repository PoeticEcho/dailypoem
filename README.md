## 1. 프로젝트 소개 & 핵심 비전

**DailyPoem 2.0**은 일상 속 거실, 서재, 침실 공간에 놓인 디스플레이를 따스한 문학 갤러리로 탈바꿈시키는 **인공지능 감성 전자액자 시스템**입니다.

- **문학적 힐링**: 351편의 정제된 현대 감성 시를 타이핑 애니메이션과 명품 한글 서체로 낭독하듯 선보입니다.
- **사진과의 공명**: 사진의 촬영 계절, 시간대, 인물 초점, 그리고 설정한 거주 지역(전국 20개 주요 도시 및 GPS 현위치)의 실시간 날씨 데이터를 분석하여 가장 어울리는 시를 자동으로 페어링합니다.
- **외부 종속 없는 순수 오디오 합성**: MP3 파일 스트리밍 없이 브라우저 내장 **Web Audio API**만으로 Altered 재즈 텐션 화성, 빈티지 Rhodes 틴 어택, LP 바이닐 틱 노이즈를 실시간 합성 연주합니다.
- **친환경 저전력/저부하 아키텍처**: 저사양 홈 NAS(Intel Celeron J4025, 2코어)에서도 주간 CPU 점유율 0%로 매끄럽게 구동되는 3중 스로틀링 새벽 배치 파이프라인을 갖추고 있습니다.

## 3. FHD (1920×1080) 대화면 시연 & 전시 가이드

전시장, 박람회, 콘테스트 심사 현장의 **16:9 FHD (1920×1080) 대화면 모니터**나 **아이패드(4:3)**에서 발표자가 마우스 조작 없이도 모든 연출을 즉각 시연할 수 있도록 직관적인 **단축키(Keyboard Shortcuts)** 체계가 내장되어 있습니다.

### ⌨️ 전시장 원터치 시연 키보드 매핑
| 단축키 | 기능 | 시연 연출 포인트 |
| :---: | :--- | :--- |
| **`Space`** | 자동 감상 재생 / 일시정지 | 잔잔한 타이핑 진행 중 일시정지하여 시 문구 집중 감상 |
| **`←` / `→`** | 이전 작품 / 다음 작품 넘김 | 즉각적인 시 및 사진 슬라이드 전환 |
| **`V`** | 액자 모드 순환 순서 전환 | `시집 전용 ➔ 하이브리드 ➔ 포토 포엠 ➔ 사진 전용` 순환 |
| **`B`** | 여백·비율 모드 순환 전환 | `가우시안 블러 ➔ 화이트 ➔ 블랙 ➔ 한지 ➔ 크롭 ➔ 2장 페어링`<br>*(가로 사진 감상 중 누르면 즉시 세로 사진으로 점프하여 여백 효과를 실시간 시연)* |
| **`M`** | Poemmood 재즈 음악 토글 | 무음 상태에서 은은한 Rhodes + 브러시 스윙 + LP 바이닐 틱 사운드 온/오프 |
| **`C`** | 사진 큐레이션 스튜디오 열기 | 드래그 앤 드롭 순서 재배치 및 초점 클릭 지정 UI 시연 |
| **`H`** | 현재 작품 하트(♥) 공감 | 화면 더블탭과 동일하게 베스트컷에 누적 등록 |
| **`F`** | 전체화면 액자 모드 토글 | 브라우저 주소창과 탭을 숨겨 순수 갤러리 액자로 전환 |
| **`Esc`** | 팝업 및 모달 즉시 닫기 | 시연 중 열린 설정창을 한 번에 닫고 갤러리 복귀 |

## 4. 6대 스마트 여백 & 화면 비율 매트 기법

스마트폰으로 촬영한 세로 사진(3:4, 9:16)을 16:9 FHD 모니터나 4:3 아이패드에 띄울 때 발생하는 여백을 예술적으로 승화시키는 6가지 기법을 제공합니다:

```
[ 1. 가우시안 블러 ]       [ 2. 인샷 화이트 ]        [ 6. 세로 2장 페어링 (Diptych) ]
┌───┬─────────┬───┐     ┌───┬─────────┬───┐     ┌───┬──────┬──────┬───┐
│░░░│  선 명  │░░░│     │   │  원 본  │   │     │░░░│ 세로 │ 세로 │░░░│
│░░░│  사 진  │░░░│     │   │  사 진  │   │     │░░░│ 사진 │ 사진 │░░░│
│░░░│ (원본)  │░░░│     │   │ (카드)  │   │     │░░░│  #1  │  #2  │░░░│
└───┴─────────┴───┘     └───┴─────────┴───┘     └───┴──────┴──────┴───┘
 (흐린 배경 복제)          (미술관 인화지)         (Aura Carver Mat 화보)
```

1. **가우시안 블러 (`fit=blur`, 기본값)**: 원본 사진을 116% 확대 복제하여 `38px` 블러와 `0.78` 명도 감광으로 은은하게 깔고, 중앙에 무손실 원본을 띄웁니다.
2. **인샷 화이트 (`fit=white`)**: 순백색 매트 보드 위에 사진을 단정하게 얹는 인스타그램 카드 스타일입니다. (야간 모드 시 다크 차콜 매트로 자동 보호).
3. **시네마틱 블랙 (`fit=black`)**: 깊은 암흑 배경으로 거실 불이 꺼진 야간에 완벽한 명암비와 몰입감을 선사합니다.
4. **따뜻한 한지 매트 (`fit=hanji`)**: DailyPoem 고유의 한지 질감(`#FBF8F3`)과 1px 마이크로 베벨 테두리를 둘러 시집과의 일체감을 구현합니다.
5. **인물 스마트 크롭 (`fit=crop_face`)**: 화면을 빈틈없이 100% 꽉 채우되, 인물 얼굴 중심 좌표(`focalX, focalY`)를 앵커로 고정하여 인물의 얼굴이나 시선이 잘리지 않습니다.
6. **세로 2장 스마트 페어링 (`fit=diptych`)**: Aura Carver 플래그십 액자 스타일로, 세로 사진 2장을 양옆으로 나란히 배치하여 16:9 화면에 최적화된 한 쌍의 화보집을 완성합니다.

## 6. 사진 큐레이션 스튜디오 (v2.7), 상단 3개 퀵 버튼 (v2.8) & 감성시계 미니바 (v2.9)

우측 상단 3개의 미니멀 플로팅 버튼과 시간·날씨바 원클릭 인터랙션을 통해 일상 감상 중 번거로운 메뉴 탐색 없이 핵심 조작을 1초 만에 수행합니다:

1. **`[♡ / ♥]` 베스트컷 토글 버튼**: 더블탭으로 공감한 사진과 시만 모아서 감상하는 필터 모드를 켜고 끕니다.
2. **`[✕]` 현재 사진 즉시 제외 버튼**: 현재 액자에 떠 있는 사진이 마음에 들지 않을 때 원클릭으로 상영 목록에서 제외하고 다음 사진으로 매끄럽게 넘어갑니다. (실수로 누른 경우 복원 버튼 자동 제공).
3. **`[⚙️]` 컴팩트 설정 팝업**: 2열/3열 그리드로 깔끔하게 정돈된 메뉴에서 모드, 여백, 음악, 시계·지역, 정렬, 글자 크기를 즉시 조절합니다.
4. **`[시간날씨바]` 원클릭 감성시계·지역 미니 설정바 (`v2.9`)**: 화면의 시간·날씨 영역을 클릭하면 시계 형태·위치·서체·농도와 전국 20개 주요 도시 및 GPS 현위치 날씨·일몰 기준 지역을 즉시 변경할 수 있으며, 상세 액자 설정(야간·주변 조도 모드 포함)과 양방향 동기화됩니다.
5. **인앱 큐레이션 스튜디오 모달 (`C`키)**:
   - **드래그 앤 드롭 순서 변경**: 썸네일을 마우스로 끌어다 놓으면 원하는 상영 순서로 재배치됩니다.
   - **원클릭 인물 초점 지정**: 썸네일 속 인물의 얼굴 위치를 마우스로 클릭하면 초점 십자선(⊕)이 이동하며 스마트 크롭 앵커가 즉시 갱신됩니다.
   - **JSON 영구 내보내기**: 수정한 순서와 초점 좌표를 담은 `media_index.json`을 원클릭으로 내려받아 NAS나 저장소에 바로 반영할 수 있습니다.

## 7. Poemmood 2.1 사운드 엔진 & 공감각 앰비언스

`poemmood-audio-engine.js`는 외부 MP3 파일 다운로드나 네트워크 스트리밍 없이, 순수 HTML5 **Web Audio API 오실레이터 및 바이쿼드 필터**로 구동되는 절차적 오디오 신디사이저입니다:

- **Altered Dominant Turnaround**: 재즈 화성학의 서정적인 텐션 코드(`b9`, `#9`, `b13`)를 사용하여 기계적이지 않고 깊이 있는 화성 진행을 연주합니다.
- **Vintage Rhodes Tine Attack**: 벨 소리의 맑은 고주파 성분과 따스한 건반의 중저역 배음을 이중 합성하여 실제 빈티지 전자 피아노의 질감을 재현했습니다.
- **실시간 LP 바이닐 틱(Vinyl Tick) & 리버브**: 미세한 아날로그 LP 잡음과 공간감 있는 컨볼루션 에코를 덧입혀 비 오는 카페 창가 분위기를 완성합니다.
- **날씨 연동 자연음**: 비나 눈이 오면 설정된 지역의 실시간 기상 데이터를 감지하여 1,400Hz 로우패스 빗소리 앰비언스가 자동으로 믹싱됩니다.

## 8. 오프라인 탑재 5대 명품 한국어 서체

인터넷이 연결되지 않은 독립형 전시장이나 로컬 NAS 환경에서도 폰트 깨짐 없이 완벽한 조판 품질을 보장하도록 5종의 상업용 무료 라이선스 서체 원본(WOFF2)이 `./fonts/` 디렉토리에 내장되어 있습니다:

1. **고운바탕 (Gowun Batang)**: 서정적인 본문 시 감상에 최적화된 단아하고 유려한 명조체.
2. **고운돋움 (Gowun Dodum)**: UI 레이블, 시계, 메타데이터에 가독성을 더하는 부드러운 고딕체.
3. **마루부리 (Maru Buri)**: 화면용 디스플레이에 최적화된 온화한 곡선의 네이버 완성형 부리체.
4. **나눔명조 (Nanum Myeongjo)**: 클래식한 문학 도서의 정통성을 담은 명조체.
5. **노토세리프 (Noto Serif KR)**: 정갈하고 또렷한 가독성을 제공하는 글로벌 표준 세리프 서체.

## 9. 시놀로지 DS420+ 저부하 CV 아키텍처

홈 NAS의 파일 공유 및 미디어 서버 성능에 일체 지장을 주지 않도록 정교하게 설계된 배치 인덱싱 아키텍처를 갖추고 있습니다:

```
[ 원본 사진 폴더 ]  ➔  [ 새벽 03:00 저부하 배치 인덱서 ]  ➔  [ FHD 1920px 캐시 / JSON ]  ➔  [ 브라우저 재생 ]
  /photos/             batch_indexer.py (os.nice=15)         /data/cache_fhd/*.jpg        낮 시간대
 (장당 5~15MB)          단일 코어(CPU 15% 제한) + 80ms 휴식   media_index.json            CPU 점유율 0%
```

- **낮 시간대 CPU 0% 스트리밍**: 주간에 액자를 재생할 때는 OpenCV나 리사이징을 전혀 구동하지 않고, 사전 캐시된 FHD 이미지만 정적 스트리밍합니다.
- **`os.nice(15)` & 단일 스레드 제한**: 타 작업 발생 시 CPU를 즉각 양보하며, 사진 처리 간격 사이에 `80ms` 휴식을 두어 듀얼코어 NAS에서도 발열이나 팬 소음이 발생하지 않습니다.
- **증분(Delta) 스캔**: 이미 분석된 사진은 파일 크기와 수정시각(`mtime`)을 통해 0.001초 만에 건너뜁니다.

## 10. 7대 유기적 연동 루프 (Cross-Module Organic Synergy)

| 연동 루프 | 연결 모듈 | 작동 메커니즘 |
| :---: | :--- | :--- |
| **1. 시맨틱 공명 루프** | 사진 EXIF + 지역 날씨 ➔ 시 선별 | 사진의 촬영 계절·시간대·인물 유무와 설정 지역 실시간 날씨 키워드를 대조하여 공명 점수가 높은 시를 자동 선택 |
| **2. 자석 N-N극 반발 루프** | 피사체 초점 + 시구 ➔ 대척점 배치 | 피사체(`focalX, focalY`)를 회피하면서 시계와 시 카드가 자석 N-N극처럼 대각선 반대편 코너로 자동 반발 이동 |
| **3. 색채 하모니 루프** | 사진 대표색 ➔ 카드 테두리/반전 | 사진의 `dominantHex`를 시 카드 테두리 광채에 투영하고, 배경 명도에 따라 UI 텍스트 흑백 자동 반전 |
| **4. 주야간 서카디안 루프** | 주변 조도 + 지역 일몰 ➔ 여백 보호 | 방 불을 끄거나 설정 지역 일몰 시 화이트 여백을 눈부시지 않은 다크 차콜(`#121418`)로 자동 전환 |
| **5. 공감각 사운드 루프** | 지역 날씨 ➔ 자연음 자동 연동 | 비/눈 예보 시 빗소리 앰비언스를 자동 믹싱하고, 심야에는 마스터 볼륨을 28% 자동 감쇠 |
| **6. 독자 큐레이션 루프** | 더블탭 하트 ➔ 베스트컷 상영 | 화면 더블탭으로 공감한 사진과 시를 메모리 및 로컬 스토리지에 기록하여 베스트컷 전용 슬라이드 구성 |
| **7. 무수정 환경 브리지** | GitHub Pages ⇄ 시놀로지 NAS | 동일한 프론트엔드 파일이 정적 웹 서버와 FastAPI 도커 백엔드 양쪽에서 단 한 줄의 수정 없이 구동 |

## 11. 배포 및 설치 안내 (GitHub Pages & Docker)

### ① GitHub Pages 웹 배포 (정적 호스팅)
1. 저장소의 `main` 브랜치에 코드를 푸시합니다.
2. GitHub 저장소의 `Settings` ➔ `Pages` ➔ `Build and deployment`에서 Source를 `Deploy from a branch`로 설정하고 `Branch: main / (root)`를 지정합니다.
3. 배포 완료 후 `https://<username>.github.io/<repo>/`로 접속하면 즉시 시집과 액자가 실행됩니다.
4. 루트의 `404.html`이 `/2341/` 형태의 공유 링크 요청을 `index.html`로 안전하게 리다이렉트합니다.

### ② 시놀로지 NAS DS420+ Docker 이식
```bash
# 1. 저장소를 클론하거나 daily-poem-self-hosted.zip 압축을 해제합니다.
cd /volume1/docker/dailypoem

# 2. Docker Compose 빌드 및 백그라운드 구동
docker compose up -d --build

# 3. (선택) 사진 폴더 초기 1회 인덱싱 즉시 실행
docker exec -it dailypoem-v2-frame python3 batch_indexer.py \
  --photos /photos \
  --cache /data/cache_fhd \
  --index /data/media_index.json
```
